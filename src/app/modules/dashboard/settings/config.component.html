About

euclid-web — an Angular admin UI for the euclid server.

The browser speaks euclid's own protocol: one POST per call, with the module in x-euclid-target and the operation in x-euclid-action, authenticated with the bearer token eam:login handed back. The item shapes are euclid-ndk's, imported as types.
